Run the Prime Piece weekly GTM review, one subagent at a time:

1. `gtm-monitor`: sweep the watch list for new signals.
2. `gtm-crm`: hygiene pass.
3. `gtm-content`: next week's content batch (3 LinkedIn + 3 X).
4. `gtm-brain`: the weekly report and next week's plan.

Return the Brain's report, followed by the content batch.
