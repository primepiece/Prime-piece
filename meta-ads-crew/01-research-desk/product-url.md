# Brief template

`/brief <url>` fills this out in `runs/<date>-<slug>/brief.md`. You can also add notes after the URL, e.g.:

```
/brief https://primepiece.co.nz/tables.html  focus on the Teal Tide coffee table, $30/day, summer entertaining
```

| Field | Value |
|---|---|
| Product URL | |
| Product(s) in focus | |
| Price | |
| Goal | Purchases (default) / Leads (custom & commissions) |
| Daily budget (NZD) | default = guardrails cap |
| Must-say | |
| Must-not-say | |
| Images to use | (repo paths, .jpg/.png) |
| Notes from James | |
