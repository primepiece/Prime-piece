# Research desk: competitor & Ad Library notes

Rita adds findings here so research compounds across briefs.

## How Rita researches
1. **The product page** (the URL in the brief): price, materials, sizes, photos in the repo, existing copy.
2. **Competitors in NZ/AU** selling stone, marble or onyx furniture, basins and boards. Use web search for their sites, price points and claims.
3. **Meta Ad Library** (facebook.com/ads/library): look up each competitor's active ads. Note how long each has been running (long-running ≈ profitable), the hook, the format and the offer.
   - ⚠️ Meta's Ad Library *API* only returns political/issue ads and ads shown in the EU, so it can't list NZ commercial ads. Rita uses web search plus the public library page. If she can't load it, she says so and asks James to paste screenshots or links instead of guessing.
4. **Reviews and comments** (Google reviews, competitor socials, Reddit r/newzealand / r/auckland home threads) for buyer language, objections and desires.
