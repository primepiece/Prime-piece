# Swipe file (Ad Library research)

Meta's Ad Library API only returns political/issue ads for New Zealand, so there's no automated "spy" on competitors' commercial ads. This file is the workaround: paste what you find and Rita uses it.

**How to add from your phone:** open facebook.com/ads/library → Country: New Zealand → All ads → search a competitor. For anything good, paste the link plus a one-line note into the Claude app ("add to swipe file: <link> — long-running, UGC, price in hook"). Ads running 30+ days are the ones worth copying the *structure* of (never the words).
